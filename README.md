# Athletic MoushiCommu Excel

参加者が送付した申込書を集約して、参加チーム並びに、参加種目を集約するマクロになります。

## 機能

- チーム集約: 読み込んだ申込書を1ブック単位で読み込みを行い、チーム情報を1チームずつ表にまとめます.
- エントリー集約: 読み込んだ申込書を1ブック単位で読み込みを行い、種目単位で表にまとめます.

## 梱包内容

- `AthleticMousiCommu.xlsm`: マクロ本体です。上記機能を実行します。実行結果は新しいシートに書き出されます。
- `template/申込書（参加団体名）.xlsx`: 読み込みに対応している申込書のテンプレートです。
- `samples/申込書（sample01）.xlsx`: 申込書テンプレートのカスタマイズ・記入例です。

### 申込書テンプレート

カスタマイズマニュアルに従い、カスタマイズが可能です。

- `(1)鑑` シートは、`AthleticMousiCommu.xlsm`の`設定`シートをカスタマイズすることで、読み込みができます。
- `(2)出場選手`、`（自動）エントリー名簿`はエントリーリストの読み込みにかかわるのでカスタマイズできません。
- `（主催）種目リスト`、`（主催）設定・リスト`を設定することで、申込書として配布できます。
